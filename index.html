Installation & First Use

Please read this before installing your first theme.

IMPORTANT — LUNA MUST BE ORIGINAL BEFORE FIRST USE

Before LUNA Theme Loader creates its first Restore Point, LUNA must be clean and original. Do not begin with manually modified theme files. The first Restore Point becomes the safe original baseline used by Restore Original.

01

Prepare LUNA

Quit LUNA completely. Make sure the installed LUNA interface/resources are original and have not been manually modified.

02

Install the Loader

Open LUNA-Theme-Loader-3.9.8.dmg and drag LUNA Theme Loader into the Applications folder.

03

First macOS Launch

If macOS blocks the app, open System Settings → Privacy & Security, choose Open Anyway, then confirm.

04

Create the Safe Baseline

On first use, let the Loader create its Restore Point only while LUNA is still clean/original. Do not interrupt this process.

05

Install a Theme

Keep LUNA closed, select the theme package in LUNA Theme Loader and start the installation. Open LUNA only after the Loader reports completion.

06

Restore Original

Quit LUNA first, then use Restore Original whenever you want to return to the original resources saved in the Restore Point.
